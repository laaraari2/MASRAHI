# مَسْرَحِي | MASRAHI

من النص إلى الخشبة · Du texte à la scène

منصة تربوية لإدارة المشروع المسرحي المدرسي من اختيار النص إلى العرض النهائي.

## الوحدات
- الرئيسية والمشاريع
- النصوص
- الإعداد والتكييف
- الشخصيات وتوزيع الأدوار
- الإخراج
- برنامج الحصص
- التداريب
- الديكور والملابس
- الصوت والإضاءة
- التتبع والتقييم
- العرض النهائي

## التقنية
Next.js · TypeScript · React · Lucide React · RTL/LTR

## التشغيل
`npm install`
`npm run dev`

ثم افتح `http://localhost:3000`.

## الحالة
هذه النسخة هي Prototype وظيفي متقدم: الواجهات والمسارات والتفاعلات الأساسية موجودة، بينما التخزين السحابي والحسابات وAI الحقيقي والتصدير PDF تحتاج ربط خدمات خلفية في المرحلة التالية.
